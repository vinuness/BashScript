# Para rodar o arquivo

# Caso esteja usando VScode
Abra o terminal (Powershell ou CMD) e rode:

    winget install --id Git.Git -e --source winget

Em seguida:

  Aperte
    
    Ctrl + Shift + P;
  Selecione 
    
    Terminal: Select Default Profile
  Utilize a opção

    Git Bash
  E por fim, abra um novo terminal!
